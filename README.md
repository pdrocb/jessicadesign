# J|S Events

One-pager de **J|S Events** — estudio de wedding & event design + styling en Hudson Valley, Nueva York.

Next.js 16 (App Router) + Tailwind v4. Sin librerías extra.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npx tsc --noEmit
npm run build
```
