# Features activas

Esta carpeta aloja únicamente especificaciones temporales de features complejas en implementación.

Cada documento debe incluir: problema, alcance, estados, decisiones, criterios de aceptación y vínculos a los documentos vivos afectados. Al terminar, el comportamiento vigente se integra a esos documentos y el plan se mueve a `docs/archive/`.

No usar esta carpeta como backlog paralelo.
